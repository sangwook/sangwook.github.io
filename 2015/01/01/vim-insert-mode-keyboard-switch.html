vim 명령모드에서 영문 키보드로 자동으로 전환되게 만들기

2015-01-01 이상욱

문제

vim의 insert mode 에서 한글을 입력하다가 ESC 로 빠져나오면 영문 키보드 레이아웃으로 바꾸기 위해 항상 <한/영 전환 키>를 눌러야 합니다. 왜냐하면 insert mode 를 제외하고는 한글 키보드는 쓸모없기 때문입니다. 그래서 insert mode 가 아니면 항상 영문 키보드 레이아웃 으로 전환되는 방법을 찾게 되었습니다. gvim 에서는 기본으로 되는 기능인데, terminal 아래에서 실행되는 vim 에서는 기본적으로 이 기능이 없습니다.

해결

몇 시간 동안의 삽질을 했지만 삽질은 생략합니다. 결론적으로는 아래의 순서로 input-source-switcher 를 빌드해서 설치합니다.

git clone git@github.com:vovkasm/input-source-switcher.git
cd input-source-switcher
mkdir build
cd build
cmake ..
make
make install

그리고 .vimrc 에 아래의 코드를 추가하면 됩니다.

if has('mac') && filereadable('/usr/local/lib/libInputSourceSwitcher.dylib')
  autocmd InsertLeave * call libcall('/usr/local/lib/libInputSourceSwitcher.dylib', 'Xkb_Switch_setXkbLayout', 'com.apple.keylayout.US')
endif

p.s,

새해입니다. 저는 새해부터 이런 비생산적인 일에 집착하고 있었습니다. 요 며칠 동안 vimrc를 정리하고 새로운 플러그인들을 찾아다니며, 마약과도 같은 개발환경 세팅으로 시간을 허비하고 있었습니다. 제자리로 돌아와야겠습니다.
