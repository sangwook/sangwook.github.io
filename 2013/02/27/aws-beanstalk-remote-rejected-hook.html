AWS Beanstalk의 [remote rejected] (hook declined) 에러

2013-02-27 이상욱

평소처럼 git aws.push 로 배포를 하던 중 갑자기 ! [remote rejected] HEAD -\> master (hook declined) 라는 에러가 떴습니다. 어디서부터 손을 대야 할지 막막했습니다.

원인을 따라가 보니, version 이 일정 개수 이상 쌓이면 더 이상 배포가 되지 않도록 설정되어 있었던 모양입니다. 오래된 version 을 정리하고 다시 시도하니 배포가 정상적으로 진행되었습니다. 에러 메시지가 이유까지 친절히 일러주었더라면 헤매는 시간을 줄일 수 있었을 텐데, 그 점이 조금 아쉬웠습니다.
