AWS Beanstalk 배포시 git aws.config 자동화

2013-02-25 이상욱

그동안은 git aws.config 명령으로 environment 를 production 인지 development 인지 일일이 바꾸어 가며 배포해 왔습니다. 매번 같은 작업을 반복하다 보니 자동화할 방법이 없을까 찾아보게 되었습니다.

알아보니 git config aws.elasticbeanstalk.application 앱이름 과 git config aws.elasticbeanstalk.environment 환경명 명령으로 같은 설정을 바꿀 수 있습니다. 이 방식이라면 스크립트로 묶어 두기에도 훨씬 수월합니다.
