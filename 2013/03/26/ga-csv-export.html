GA 데이터를 CSV로 export

2013-03-26 이상욱

http://ga-dev-tools.appspot.com/explorer/ 에서 GA Core API로 데이터를 쿼리해 보는 것을 테스트할 수 있습니다. 다만 제가 원했던 것은 앱 버전별 주 단위 사용자 데이터였는데, API 문서에는 나와 있지 않았습니다. 그래서 임의로 dimensions에 ga:week,ga:appVersion을 넣어 보았더니 의외로 잘 동작합니다.

여기서 받아 온 데이터를 한 라이브러리의 인자에 그대로 넣으면 export까지 무리 없이 됩니다. 그런데 MySQL의 주 번호와 1이 차이가 나는 것 같습니다. 둘 다 1부터 시작인데 왜 이런 차이가 생기는지는 모르겠습니다.
